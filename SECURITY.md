# Security Policy

## Report a vulnerability

Do not open a public issue for a security problem.

Report it in private on GitHub: open the **Security** tab of this repository and select **Report a vulnerability**.

Include:

- the affected version or commit;
- what an attacker can do;
- the steps to reproduce the problem;
- a suggested fix, if you have one.

## Supported versions

We release security fixes for the latest version only.

## Scope

**In scope**: the code in this repository:

- the web app (single file and progressive web app);
- Valesta for Windows (`desktop/`);
- Valesta for Android (`native/android`) and the iOS shell (`native/ios`);
- the MCP server (`mcp/`);
- the build tools.

**Out of scope**:

- third-party services that the app can connect to, for example AI providers, map services and public registers;
- installations that third parties changed.

## What to expect

- We acknowledge your report within 5 working days.
- We assess the report. When we confirm the problem, we plan a fix and keep you informed.
- Coordinated disclosure: we publish an advisory when a fix is available. We credit you if you want.

## Personal data

Never include real personal data, client documents, API keys or credentials in reports, issues or test files.
